Prism 演示站点

这个页面故意留有各种问题。点下面的按钮制造数据，然后去看板查看。

首屏大区块（LCP 元素）
第一步 · 选几个按钮点一遍
第二步 · 打开看板看结果
怎么玩
  1. 先在这个页面点几个上面的按钮（每个操作都会被记成「面包屑」）
  2. 点绿色的「打开看板查看」
  3. 看板四个 Tab：概览 / 错误 / 性能 / 网络，分别点开看看
  4. 想从头演示一遍，回来点「清空本地数据」

所有数据存在浏览器本地的 IndexedDB 里，不会发往任何服务器。 演示站点和看板必须在同一个域名下打开才能共享数据 —— 用 npm run serve 启动本地服务，别直接双击 HTML 文件。
